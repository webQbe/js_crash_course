# JavaScript Crash Course
This repo is an adaptation of [JavaScript Crash Course For Beginners](https://www.youtube.com/watch?v=hdI2bqOjy3c&list=PLillGF-RfqbbnEGy3ROiLWk7JMCuSyQtX&index=1&pp=iAQB) by Brad Traversy. 

I followed the tutorial to learn followings:
- DOM - Document Object Model
- Single Element Selectors
- Multiple Element Selectors
- Looping
- Manipulating the DOM
- Adding styles
- Displaying form input data
- OOP - Object Oriented Programming
- Functions
- Conditionals
- Loops, Map and Filter
- Object Literals
- Arrays
- Strings
- Data Types
- Variables
